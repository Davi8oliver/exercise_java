## 📖 Sobre

Repositório pessoal para guardar os exercícios que resolvo em Java durante meus estudos. Não é um projeto de demonstração: serve apenas para praticar, organizar o que aprendi e consultar depois.

## 🧠 Tópicos praticados

- Variáveis, operadores e entrada de dados (`Scanner`)
- Estruturas condicionais e de repetição
- Métodos

> Os tópicos são atualizados conforme novos exercícios são adicionados.
